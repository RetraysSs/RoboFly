## Objective

Implement a leaky integrate-and-fire (LIF) simulator for a single neuron driven by an input current. This is the building block for the network simulator in v0.2.

## Background

A LIF neuron has a membrane potential `v` that:

1. leaks back toward a resting value `v_rest`,
2. is pushed up by an input current,
3. emits a spike and is reset to `v_reset` when it reaches the threshold `v_th`.

Continuous-time equation:

```
tau_m * dv/dt = -(v - v_rest) + r_m * i_ext(t)
```

Forward Euler discretisation (`dt` is the time step):

```
v[t+1] = v[t] + dt / tau_m * ( -(v[t] - v_rest) + r_m * i_ext[t] )
```

After each update, if `v >= v_th`, the spike time is recorded and `v` is set to `v_reset`.

Units: time in **ms**, potential in **mV**, current in **nA**, resistance in **MOhm** (nA x MOhm = mV).

## Interface

File: `src/flybot/lif.py`

```python
def simulate_lif(
    i_ext,            # 1-D array, input current in nA, one value per time step
    dt,               # time step in ms
    *,
    tau_m=20.0,       # ms
    v_rest=-70.0,     # mV
    v_reset=-75.0,    # mV
    v_th=-50.0,       # mV
    r_m=10.0,         # MOhm
    t_ref=0.0,        # ms, refractory period (0 = none)
):
    """Return (v, spike_times).

    v: array, same length as i_ext, membrane potential at each step
    spike_times: array of spike times in ms
    """
```

Conventions to decide and document in the docstring:

- Initial value of `v` at step 0 (the tests assume `v_rest`).
- The time assigned to a spike (the step at which `v` crossed threshold, or the following one). It must be applied consistently.
- Whether the stored `v` on a spike step is the pre-reset peak or `v_reset`.

The refractory period (`t_ref`) must have no effect when it is `0.0`. With `t_ref > 0`, no two spikes may be closer than `t_ref` (covered by a test).

## Implementation notes

- Start with a plain Python loop. A single neuron has a sequential dependency between steps, so vectorisation across time does not apply here (it becomes relevant across neurons in v0.2).
- `tests/test_lif_single.py` defines correctness. Each test checks one property of the model, and the failure message names the violated property.
- The rheobase (smallest constant current that produces a spike) follows from the steady state of the equation at `dv/dt = 0`.
- For a constant supra-threshold current the inter-spike interval has a closed form; the regular-firing test compares against it.
