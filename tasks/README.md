# tasks/

Task specifications for the current version. Each file describes one unit of work: objective, background, interface, deliverables and acceptance criteria.

Naming: `v<version>-<number>-<topic>.md`, for example `v0.1-01-single-lif-neuron.md`.

Completed tasks stay in the folder with their status set to `done`, so the history of what was specified remains visible next to the code and tests.
